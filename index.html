背對背 MOSFET 體二極體分析 (Back-to-Back Configuration)
電路拓撲 (Source-Source 相接): AC(L) ───┤D Q1 S├───═══───┤S Q2 D├─── LED ─── AC(N) │ 共同 Source 節點 Q1 體二極體: S → D (指向 AC 方向) Q2 體二極體: S → D (指向 LED 方向) ※ 兩個體二極體背對背，當兩 MOS 都 OFF 時可阻斷雙向電流

此配置的優勢：背對背體二極體可阻斷交流電

正半週 (L→N，電流: AC → Q1(D→S) → Q2(S→D) → LED): 過零點 → Q2先ON → [DT1] → Q1 ON → 導通 → Q1先OFF → [DT2] → Q2 OFF 負半週 (N→L，電流: LED → Q2(D→S) → Q1(S→D) → AC): 過零點 → Q1先ON → [DT1] → Q2 ON → 導通 → Q2先OFF → [DT2] → Q1 OFF

為何此開關時序可避免體二極體導通？

• 正半週 (電流方向: L → Q1(D→S) → Q2(S→D) → LED → N):

- Q2 體二極體方向 S→D 與電流方向相同，若 Q2 OFF 則體二極體會導通

- 所以 Q2 先 ON，讓電流走通道而非體二極體

- Q1 體二極體方向 S→D 與電流方向相反，自然阻斷

- 關閉時 Q1 先 OFF，電流立即被 Q1 體二極體阻斷 ✓

• 負半週 (電流方向: N → LED → Q2(D→S) → Q1(S→D) → L):

- Q1 體二極體方向 S→D 與電流方向相同，若 Q1 OFF 則體二極體會導通

- 所以 Q1 先 ON，讓電流走通道而非體二極體

- Q2 體二極體方向 S→D 與電流方向相反，自然阻斷

- 關閉時 Q2 先 OFF，電流立即被 Q2 體二極體阻斷 ✓

結論：此開關時序配合 S-S 背對背配置，可以完全避免體二極體導通！

注意事項：

• Dead Time 仍需存在以確保開關安全轉換

• 建議 Dead Time 保持最小值以減少切換損耗

Vds 波形與非理想模型說明

• 理想狀態下，正半週由 Q1 阻斷：Q1 OFF 時 Q1 Vds ≈ 當下 Vac；Q2 Vds ≈ 0。負半週由 Q2 阻斷，角色互換。

• 後沿調光的關斷瞬間，阻斷元件的 Vds 會從 0 升到當下 Vac 瞬時值；非理想模式下這段上升發生在 Miller 平台期間，dv/dt 由 tf 與平台長度決定（這就是後沿調光降低 EMI 的方式）。

• 若第一顆 MOS 的通道還沒完全關斷（平台尚未結束），第二顆的 Vgs 就已經低於 Vth，電流會改走第二顆的體二極體，波形上以紅色區域標示。

模型簡化：純電阻負載、Vgs 為線性斜坡、Vth/平台電壓固定（3V/5V）、平台長度 ∝ |Vac|、忽略 Rds(on) 壓降、寄生電容 Coss 與驅動延遲。數值僅供觀察趨勢，不代表特定元件的實測值。
